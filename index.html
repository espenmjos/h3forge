How to use the files
  • Large portraits are 58×64 px (HPL…), small ones 48×32 px (HPS…), PCX with at most 256 colours.
  • The 8-bit files never use palette entry 0. The game can treat that colour specially, so leaving it unused avoids graphic glitches.
  • Hero list follows HotA 1.8.1 (with Cove, Factory and Bulwark). File names for the 156 original heroes are confirmed. For HotA heroes the large name is confirmed but the small name is derived from it, and Bulwark names are not published yet. Check them against HotA.lod with MMArchive and edit the fields if needed.
  • Use the 8-bit PCX. Tested: dropping it into Heroes3\Data works. A standard 24-bit PCX shows up as random colours, because the game reads portraits as 256-colour images. The experimental option writes true colour in the game's own .pcx layout. It is untested, so back up your 8-bit files before you try it.
  • The files are named after the hero portrait you replace; put them in Heroes3\Data or pack them into a .lod with a tool such as MMArchive.
  • Check how your HotA version loads custom resources before shipping a map to other players: they need the same files installed.
